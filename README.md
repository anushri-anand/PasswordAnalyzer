# Password Strength Analyzer

A Python project that checks the strength of a password (Weak / Medium / Strong) and stores results in a SQLite database.

## Features
- Checks password length, uppercase letters, numbers, and symbols
- Stores results in a SQL database
- Displays summary of password strengths

## How to Run
1. Make sure Python 3 is installed
2. Run the program:

```bash
python3 password_analyzer.py
